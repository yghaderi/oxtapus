# رفع اشکال

**برای نماد هیچ ردیفی نیومده:** اول `instrument_search` رو صدا بزن و نام دقیق نماد رو ببین.
بعد `failures` نتیجهٔ پیشرفته رو بررسی کن. Oxtapus بین چند نتیجهٔ مشابه، یکی رو تصادفی انتخاب
نمی‌کنه.

**نام دلار یا سکه قبول نمی‌شه:** از «دلار»، «دلار نیما»، «یورو»، «سکه امامی» یا «نیم‌سکه»
استفاده کن. فاصله و نیم‌فاصله مهم نیست. پیام خطا ورودی تو و نام‌های پشتیبانی‌شده رو نمایش
می‌ده.

**خطای موقت HTTP می‌بینی:** رویدادهای تلاش مجدد و `retry_count` رو بررسی کن. timeout یا بودجهٔ
تلاش مجدد رو با سقف مشخص افزایش بده و محدودیت نرخ درخواست رو خاموش نکن.

**خطای اعتبارسنجی طرح‌واره داری:** پاسخ پاک‌سازی‌شدهٔ Bronze رو نگه دار، fingerprintها رو
مقایسه کن و دستور `oxtapus provider tsetmc doctor` رو اجرا کن. قبل از فهم دقیق تغییر منبع،
فیلدهای اجباری رو اختیاری نکن.

**PyArrow، Pandas یا DuckDB import نمی‌شه:** extra مربوطه رو نصب کن؛ مثلاً
`pip install 'oxtapus[pandas]'`.

**داخل Jupyter مشکل اجرای ناهمگام داری:** از `AsyncClient` و `await` مستقیم استفاده کن؛ دورش
`asyncio.run` نذار.
