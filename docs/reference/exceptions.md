# خطاها

همهٔ خطاهای بسته از `OxtapusError` ارث می‌برن. شاخه‌های جداگانه‌ای برای تنظیمات، قابلیت
پشتیبانی‌نشده، در دسترس نبودن نقطهٔ پایانی، شبکه و HTTP، تمام‌شدن تلاش‌های مجدد، پاسخ یا
طرح‌وارهٔ نامعتبر، تغییر طرح‌واره، کیفیت داده، ذخیره‌سازی، ابزار پیدا‌نشده یا مبهم، شناسهٔ
نامعتبر و شکست بخشی از درخواست گروهی وجود داره.

`RetryExhaustedError.original` علت نهایی رو نگه می‌داره و خطای ابهام هم گزینه‌های منطبق رو
حفظ می‌کنه. برای نام دارایی TGJU نامعتبر، پیام خطا ورودی اصلی کاربر و فهرست همهٔ نام‌های مجاز
رو نشون می‌ده.
